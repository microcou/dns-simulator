# DNS Simulator

Work In Progress...

Preview available here: [DNS Simulator](https://microcou.github.io/dns-simulator)

## Guidelines

- Light web application: no backend, no authentication
- Persistence using the browser's storage solutions, or local files
- Mindful dependencies

## Hosting

Hosted on Github Pages for now.  

Github Pages does not permit SPA fallback (rewriting to index.html), so it requires hash-based routing. If this workaround proves limiting, the project will move to a different hosting solution.

## Development

To start developing the DNS Simulator, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/microcou/dns-simulator.git
   cd dns-simulator
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
